# smart-wireframe

キャンバスに置いた図形から、絶対配置の HTML と CSS を書き出す React コンポーネントです。画面は左が編集、中央が変換、右がソースです。

UI の文言は日本語です。ライセンスは Apache License 2.0 です。

## できること

- 長方形、円、テキスト、ボタンを置く
- ドラッグで移動し、四隅のハンドルでサイズを変える。円は右端のハンドルで半径を変える
- 座標、サイズ、色、角丸、文言、文字サイズ、キャンバスサイズを編集する
- 10px スナップとグリッド表示を切り替える
- 選択中の図形を最前面または最背面へ移す、削除する、キャンバスを空にする
- キャンバス定義を JSON で書き出し、読み戻す
- 生成した HTML と CSS をコピーする、またはファイルでダウンロードする

## リポジトリの中身

| ファイル | 内容 |
| --- | --- |
| [`App.jsx`](App.jsx) | コンポーネント本体。既定エクスポートは `WireframeBuilder` |
| [`LICENSE`](LICENSE) | Apache License 2.0 |

`package.json`、エントリ HTML、Tailwind の設定、テストは含みません。`App.jsx` を、React と Tailwind CSS がある画面へ読み込んで使います。

## 動かし方

依存は React 18 と Tailwind CSS です。JSX に書いた `grid` や `col-span-5` などのユーティリティは、Tailwind の `content` に `App.jsx` を含めると生成されます。

```jsx
import WireframeBuilder from "./App.jsx";

export default function Page() {
  return <WireframeBuilder />;
}
```

`.btn`、`.btn-primary`、`.btn-danger`、`.inp`、`.lbl`、`.codebox` は、ファイル末尾で `<style>` に `@apply` を注入して定義しています。Tailwind のビルドも CDN も、実行時に差し込んだ `@apply` は展開しません。ホストの CSS で同じクラスを定義するか、その定義を PostCSS が処理する CSS ファイルへ移してください。移す前は、ボタンと入力欄がブラウザ標準の見た目になります。

レイアウトは 12 カラムで、編集 5、変換 2、ソース 5 です。広いウィンドウを前提にしています。

## 操作

1. ツールで図形の種類を選ぶ。次にキャンバスをクリックすると、その図形が 1 つ追加され、ツールは「選択」に戻る。追加位置は常に `(40, 40)`。
2. 図形をドラッグして移動する。スナップがオンのときは 10px 刻み。
3. 選択中の図形には緑の点線とハンドルが付く。長方形、テキスト、ボタンは四隅から幅と高さを変える。円は右端のハンドルから半径を変える。
4. キャンバス下のインスペクタで数値と文言を変える。値は入力のたびにキャンバスへ反映される。
5. 「前面へ」はその図形を最前面へ、「背面へ」は最背面へ移す。
6. 中央の「ワイヤーフレームのHTML/CSS化」で右ペインを更新する。図形を編集したあとは、もう一度押すまでソースは前回のまま。

キャンバスの初期サイズは幅 900、高さ 600。どちらも最小 200。削除、全消去、上書きインポートに確認ダイアログはない。

## 保存形式

「エクスポート(JSON)」は `wireframe.json` をダウンロードする。中身はキャンバスサイズと図形の配列。

```json
{
  "canvas": { "width": 900, "height": 600 },
  "shapes": [
    {
      "id": "ab12cd3",
      "type": "rect",
      "x": 40,
      "y": 40,
      "w": 200,
      "h": 120,
      "rx": 8,
      "fill": "#94a3b8",
      "stroke": "#0f172a",
      "z": 1725200000000
    }
  ]
}
```

`type` は `rect`、`circle`、`text`、`button` のいずれか。

| type | 追加時の主な値 |
| --- | --- |
| `rect` | `w: 200`, `h: 120`, `rx: 8`, `fill: #94a3b8` |
| `circle` | `r: 60`。`x` と `y` は中心点以外の、外接矩形の左上 |
| `text` | `w: 240`, `h: 40`, `text: "見出し"`, `fontSize: 20`, `fill: #111827` |
| `button` | `w: 160`, `h: 44`, `rx: 10`, `text: "ボタン"`, `fontSize: 16`, `fill: #2563eb` |

`id` はランダムな短い文字列、`z` は重なり順（大きいほど手前）です。読み込み時は、トップレベルに `canvas` と `shapes` があることだけを確認します。図形の中身の検証、形式のバージョン、同じファイルの再選択による再読み込みはありません。

## 生成される HTML と CSS

出力は、キャンバスと同じ幅と高さの `div.wf-container` と、その中へ絶対配置した要素です。座標、サイズ、背景色、文字サイズは要素の `style` 属性に入ります。枠線、角丸、フォントはクラス側の固定値です。文言は HTML エスケープされます。

ダウンロードファイルは次のとおりです。

| ファイル | 中身 |
| --- | --- |
| `wireframe.html` | `<div class="wf-container">` から始まる断片。文書全体ではない |
| `wireframe.css` | `.wf-container`、`.wf-abs`、`.wf-rect`、`.wf-button`、`.wf-text` |
| `wireframe.json` | エディタの状態 |

`wireframe.html` を単体で開くと、配置に必要な CSS が無く、図形はドキュメントフローに落ちます。CSS ファイルと組み合わせて使ってください。右ペインのテキストエリアは手編集できます。編集結果を図形へ戻す経路はありません。

エディタの表示と出力がずれる箇所は次のとおりです。

- 長方形の角丸は CSS の 8px、ボタンの角丸は 10px。インスペクタの角丸は出力に入らない。
- テキスト図形は、エディタでは白地に枠線付きの箱として見える。出力は枠の無い文字だけで、`fill` は文字色になる。
- ボタンの文字色は白で固定。
- 各図形は `stroke` を持つ。出力の枠線色は `#0f172a` で固定。

## いまの制限

- 図形は 4 種類。線、画像、入力欄、チェック、グループ、整列はない。
- 出力は固定ピクセルの絶対配置。画面幅には追従せず、ボタンもリンクもフォームも動作しない。
- 生成結果のプレビューと、HTML と CSS を 1 ファイルにまとめた書き出しはない。
- 元に戻す操作、自動保存、キーボードでの削除、複数選択、拡大縮小はない。
- 移動とリサイズはマウスイベントだけを見る。
- グリッドの描画は 10px のマス目になっていない。スナップの刻みと見た目は対応しない。
- テストと CI はない。
