# smart-wireframe

キャンバスに置いた図形から、絶対配置の HTML と CSS を書き出すツールです。画面は左が編集、中央が変換、右がソースとプレビューです。

編集内容はブラウザの `localStorage` に自動保存されます。ライセンスは Apache License 2.0 です。

## できること

- 長方形、円、テキスト、ボタンを、クリックした位置に置く
- ドラッグで移動し、四辺と四隅のハンドルでサイズを変える。円は右のハンドルで半径を変える
- 10px のグリッド表示と、移動・追加・リサイズのスナップ
- 塗り、枠線、角丸、文言、文字サイズ、文字色、テキストの背景、キャンバスサイズを編集する
- 重なり順の変更、重なり一覧からの選択、複製、削除
- `⌘Z` / `Ctrl+Z` で元に戻す、`⇧⌘Z` / `Ctrl+Y` でやり直す。`Delete` で削除、`⌘D` / `Ctrl+D` で複製
- キャンバス定義の JSON 書き出しと読み込み
- 生成した HTML 断片と CSS のコピー、CSS ファイルのダウンロード
- CSS を埋め込んだ単体で開ける HTML ファイルのダウンロードと、そのプレビュー

## 開発

依存は Node.js です。

```bash
npm install
npm run dev
```

開発サーバは `http://127.0.0.1:5173` で開きます。

```bash
npm test
npm run build
```

`npm test` は図形の幾何と HTML 生成を検証します。`npm run build` は `dist/` を作ります。

| パス | 内容 |
| --- | --- |
| `src/App.jsx` | 画面 |
| `src/model.js` | 図形、スナップ、JSON の正規化、自動保存の読み込み |
| `src/export.js` | HTML / CSS と、単体 HTML 文書の生成 |
| `index.html` | エントリ |

## 操作

1. ツールで図形を選び、キャンバスをクリックする。図形はその位置に追加され、ツールは「選択」に戻る。円はクリック地点が中心になる。端に近いときは、図形がキャンバス内に収まるよう位置をずらす。
2. 図形をドラッグして移動する。スナップがオンのときは 10px 刻みで、図形全体がキャンバス内に収まる。
3. 選択中の図形には緑の点線とハンドルが付く。箱型は四辺と四隅、円は右端から大きさを変える。箱の一辺の最小は 20、円の半径の最小は 10。
4. キャンバス下の欄で数値と文言を変える。入力のたびに反映される。
5. 「前面へ」は最前面へ、「背面へ」は最背面へ移す。「重なり」の一覧からも選択できる。
6. 中央のボタンで右の HTML、CSS、プレビューを更新する。図形を編集したあとは、もう一度押すまでソースは前回のまま。

キャンバスの初期サイズは幅 900、高さ 600。どちらも最小 200。全消去は確認してから図形だけを消す。キャンバスサイズは残る。

ポインタ操作はマウス、タッチ、ペンで共通です。

## 保存形式

「エクスポート(JSON)」は `wireframe.json` をダウンロードする。自動保存も同じ形に、グリッドとスナップの設定を足したものです。

```json
{
  "canvas": { "width": 900, "height": 600 },
  "shapes": [
    {
      "id": "3f1c1a4e-6b0d-4f3a-9c1e-2a7b8d9e0f11",
      "type": "rect",
      "x": 40,
      "y": 40,
      "w": 200,
      "h": 120,
      "rx": 8,
      "fill": "#94a3b8",
      "stroke": "#0f172a",
      "z": 1725200000001
    }
  ]
}
```

`type` は `rect`、`circle`、`text`、`button` のいずれか。`z` が大きいほど手前に描く。

| type | 追加時の値 |
| --- | --- |
| `rect` | `w: 200`, `h: 120`, `rx: 8`, `fill: #94a3b8` |
| `circle` | `r: 60`。`x` と `y` は中心ではなく、外接矩形の左上 |
| `text` | `w: 240`, `h: 40`, `rx: 6`, `text: "見出し"`, `fontSize: 20`, `fill: #111827`, `background: #ffffff` |
| `button` | `w: 160`, `h: 44`, `rx: 10`, `text: "ボタン"`, `fontSize: 16`, `fill: #2563eb`, `color: #ffffff` |

`fill` は塗りです。テキストでは文字色です。ボタンの文字色は `color`、テキストの地色は `background` です。古い JSON にこれらのキーが無くても、読み込み時に上記の初期値を補います。未知の `type` は捨て、キャンバスの辺は 200 未満にしない。同じファイルを続けて選んでも、もう一度読み込みます。

## 生成される HTML と CSS

出力は、キャンバスと同じ幅と高さの `div.wf-container` と、その中へ絶対配置した要素です。座標、サイズ、色、角丸、文字サイズは要素の `style` に入り、重なり順は `z` の昇順です。文言は HTML エスケープされます。ボタンは `<button type="button">` です。

右の HTML 欄は断片です。プレビューと「HTMLをダウンロード」は、その断片に CSS を埋め込んだ完全な HTML 文書です。`wireframe.html` は単体で開けます。`wireframe.css` はスタイルだけです。

テキスト欄を手で直した内容はプレビューに出ます。図形へは戻りません。

## 制限

- 図形は 4 種類。線、画像、入力欄、チェック、グループ、整列、ズームはない。
- 出力は固定ピクセルの絶対配置。画面幅には追従しない。ボタンは押せる要素だが、遷移や送信はしない。
- 複数選択はない。
- 変換結果は元に戻す履歴の外。図形を変えたあとは、変換し直すとソースが追従する。
- テストは幾何と生成結果を対象にしていて、ブラウザ操作そのものは含まない。
